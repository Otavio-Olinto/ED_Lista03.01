# ED_Lista03.01
## Número de Dígitos: Recursiva

Este desafio consiste em criar uma aplicação, em Java, que indique a quantidade de dígitos de um número natural.

```
Requisitos do projeto:

1. Arquitetura MVC;
2. A operação deve ser realizada por uma função recursiva;
3. Declarar, via comentário, a condição de parada da função.
```
